# Laboratorio de Robótica Ensamblador 2

Bienvenido al repositorio del Laboratorio de Robótica para el ensamblador 2 . Este repositorio contiene toda la documentación, códigos fuente y manuales de usuario desarrollados para la implementación de nuestro robot esamblador


## Arquitectura General de la Solución

El objetivo principal de este sistema es ejecutar operaciones de pick-and-place (recogida y posicionamiento) con alta precisión. Específicamente, el manipulador está encargado de desplazarse hacia coordenadas espaciales predefinidas en su espacio de trabajo para recolectar productos (chocolates) y depositarlos en el interior de una caja de empaque. Esta tarea requiere un alto nivel de control para garantizar que la manipulación y la inserción del producto se realicen de manera suave, secuencial y ordenada, salvaguardando así la integridad física de los elementos manipulados


## Herramientas Utilizadas

* **Sistema Operativo / Middleware:Ubuntu-Ros2-Jazzy
* **Simulación: Gazebo y Rviz
* **Control y Hardware: Motores JGA25-370 con encoder , Puente H LN298, ESP32
* **Diseño CAD:SolidWorks
* **Lenguajes de Programación:Micropython, python
