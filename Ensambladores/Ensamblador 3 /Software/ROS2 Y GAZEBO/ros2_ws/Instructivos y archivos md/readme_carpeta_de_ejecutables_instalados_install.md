# Carpeta de Programas Instalados (`install/`)

Esta carpeta es **generada automáticamente** por `colcon build` y contiene los paquetes ya compilados y listos para ejecutarse en ROS 2.

## Instructivo básico
* Antes de usar el robot en cualquier terminal nueva, debes activar el entorno con:
  `source install/setup.bash`
* Si modificas algún archivo dentro de `src/`, recuerda ejecutar `colcon build` para actualizar los programas de esta carpeta.
