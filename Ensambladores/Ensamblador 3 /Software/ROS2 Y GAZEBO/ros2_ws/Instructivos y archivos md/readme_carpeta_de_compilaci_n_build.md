# Carpeta de Compilación (`build/`)

Esta carpeta es **generada automáticamente** por ROS 2 al ejecutar `colcon build`. Contiene archivos intermedios de compilación.

## Instructivo básico
* **No edites ni guardes código aquí adentro**, ya que se sobrescribe cada vez que compilas.
* Si alguna vez ocurre un error extraño de compilación, puedes borrar esta carpeta (`rm -rf build`) y volver a ejecutar `colcon build`.
