# Marcador de Paquete ROS 2 (`resource/`)

Esta carpeta es un requisito estructural de ROS 2 para paquetes escritos en Python (`ament_python`).

## Archivos importantes
* **`scara_kinematics`**: Archivo vacío (0 bytes) que le indica al compilador `colcon` que este directorio es un paquete válido de ROS 2.

## Instructivo básico
* **No borres ni cambies el nombre** del archivo `scara_kinematics`, ya que el sistema dejaría de compilar.
