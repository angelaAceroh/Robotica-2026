# Configuración del Exportador URDF (`scara_urdf/config/`)

## Archivos importantes
* **`joint_names_scara_urdf.yaml`**: Lista de nombres de articulaciones generada por el exportador de SolidWorks.

## Instructivo básico
* Se mantiene por compatibilidad con el paquete URDF. La configuración activa utilizada por los nodos del robot está en `src/scara_kinematics/config/scara_urdf3.yaml`.
