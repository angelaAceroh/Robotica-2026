# Vistas de RViz2 (`scara_urdf/rviz/`)

Configuraciones de visualización para inspeccionar el modelo CAD del robot.

## Archivos importantes
* **`urdf.rviz`**: Vista cargada por defecto al ejecutar `display.launch.py`.
* **`scara.rviz`**: Vista alternativa del ensamblaje 3D.

## Instructivo básico
* Se cargan automáticamente al iniciar `display.launch.py`.
