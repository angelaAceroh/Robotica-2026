# Carpeta de Registros y Logs (`log/`)

Aquí se guardan automáticamente los historiales de cada compilación (`colcon build`) y las bitácoras de sesión del robot (como `scara_sesion.log`, `tray_sesion.log` y `traycho_garra.log`).

## Instructivo básico
* Si algo falla al compilar o al operar el brazo, revisa los archivos `.log` más recientes de esta carpeta para consultar el detalle del error.
