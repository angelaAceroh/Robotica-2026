# Piezas Tridimensionales 3D (`scara_urdf/meshes/`)

Contiene los archivos geométricos `.STL` exportados desde SolidWorks que forman visualmente el robot SCARA.

## Archivos importantes
* **`Alvin.STL`**: Base fija del robot.
* **`Simon.STL`**: Primer eslabón (hombro).
* **`Teodoro.STL`**: Segundo eslabón (codo que sostiene el eje vertical).
* **`Dave.STL`**: Husillo vertical (eje Z).
* **`Ian.STL`**: Soporte inferior / efector final.

## Instructivo básico
* RViz y Gazebo cargan estas mallas automáticamente. **No cambies los nombres de estos archivos.**
