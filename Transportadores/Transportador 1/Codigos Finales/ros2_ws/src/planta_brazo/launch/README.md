# planta_brazo · launch

Se lanzan con `ros2 launch planta_brazo <archivo>`.

| Archivo | Qué es |
|---|---|
| `control_cinematico.launch.py` | Launch: Control cinematico por jacobiano inverso en Gazebo. |
| `display.launch.py` | Launch: RViz con el panel de sliders. |
| `espejo.launch.py` | Launch: Gazebo repite lo que hace el robot fisico. |
| `gazebo.launch.py` | Launch: Gazebo + puente ROS + panel o demo + RViz. |
| `trayectoria_lineal.launch.py` | Launch: recta A-B por cinemática inversa en Gazebo. |
| `trayectoria_perfiles.launch.py` | Launch: Panel de planeacion de trayectorias con perfiles de velocidad. |
