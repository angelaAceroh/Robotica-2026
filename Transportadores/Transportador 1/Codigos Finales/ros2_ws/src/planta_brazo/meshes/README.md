# planta_brazo · meshes

Mallas STL del CAD que se dibujan en RViz y Gazebo. Las del gripper están en milímetros (escala 0,001 en el URDF).

| Archivo | Qué es |
|---|---|
| `BASE.STL` | base |
| `BRAZO1.STL` | soporte del hombro (gira con J1) |
| `Brazo2.STL` | eslabón hombro-codo |
| `Brazo3.STL` | antebrazo largo del CAD (no montado; comentado en el URDF) |
| `TAPA.STL` | tapa de la base (aloja el rodamiento y el motor de J1) |
| `cremallera_def.STL` | cremallera con las palas (cremadef) |
| `gripper_def.STL` | gripper definitivo (Brazo33def) |
| `gripper_nuevo.STL` | gripper provisional (ya no se dibuja) |
